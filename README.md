# Сетеметр

Нативный индикатор интернета для macOS 13 и новее. SwiftUI и AppKit.

Откройте Сетеметр.app. Карточка появится у правого верхнего края рабочего стола, а значок состояния — в строке меню. Карточку можно перетащить за верхнюю строку Сетеметр, закрыть крестиком и снова открыть из меню Сетеметр. Через это же меню можно завершить приложение.

Пока Mac бодрствует, приложение раз в секунду отправляет две параллельные HTTPS HEAD-проверки к Cloudflare и Google. Достаточно одного ответа HTTP 204. Если оба адреса недоступны или не успевают ответить за 0,9 с, приложение показывает «Нет ответа». Задержка в карточке — время первого успешного HTTPS-ответа. График хранит последние 30 результатов в памяти.

Карточка — окно приложения AppKit. Это даёт ей тот же интервал обновления, что и значку в меню.

## Диагностика

Короткая сводка показана на рабочем столе и в строке меню. Кнопка со спидометром запускает тест прямо из карточки. Подробный отчёт открывается кнопкой «Диагностика». Расширенная проверка запускается при старте приложения, раз в две минуты, при открытии окна и по кнопке «Обновить». Она показывает внешний IPv4/IPv6 по данным ipify, который видит текущий маршрут, локальные адреса, шлюз, DNS, VPN и прокси macOS. Отдельные проверки измеряют пинг шлюза, разрешение имени через системный DNS (возможен кэш), HTTPS к Apple, Google, Cloudflare и HTTPS по IP. Таймаут HTTPS — 5 секунд. Кнопка «Измерить скорость» выполняет три последовательные загрузки по 5 МБ с Cloudflare, рассчитывает среднее по трём замерам и показывает оценку в Мбит/с. Время запроса входит в замер. При запуске Сетеметр начинает замер автоматически (15 МБ за запуск). Карточка сразу показывает последний сохранённый результат и обновляет его после нового замера. Периодических загрузок для замера нет. Отчёт можно скопировать кнопкой внизу окна.

## Сборка

Установите Command Line Tools для Xcode и запустите в этом каталоге:

```sh
./build.sh
open build/Сетеметр.app
```

Скрипт создаёт универсальную сборку для Apple silicon и Intel и подписывает её локальной ad hoc подписью.

## Обновления

Выпуск новой версии:

```sh
git tag v1.5 && git push --tags
```

Для установки вручную в релизе есть `Setemeter.dmg` (перетащите приложение в «Программы»). `Setemeter.zip` нужен для самообновления из приложения. По тегу `v*` GitHub Actions (`.github/workflows/release.yml`) собирает приложение на macos-14, упаковывает его в `Setemeter.zip`, считает `Setemeter.zip.sha256` и создаёт релиз с этими двумя файлами.

Как работает проверка: при запуске и затем раз в 6 часов Сетеметр запрашивает последний релиз через GitHub API и сравнивает его версию (тег без префикса `v`) с версией приложения по числовым компонентам. Окна не открываются, результат виден в карточке и в меню: «Доступна версия X — Обновить» или «Установлена последняя версия». При обновлении архив скачивается во временную папку, проверяется по `Setemeter.zip.sha256` (без этого файла установка отменяется), распаковывается, и отдельный скрипт заменяет приложение и перезапускает его. Если у приложения нет прав на запись в его каталог, переместите его в `/Applications`.

Для публичного репозитория токен не нужен. Для приватного можно сохранить персональный токен GitHub в Keychain: сервис `Setemeter`, аккаунт `github-token`. Токен нигде не хранится в коде.
